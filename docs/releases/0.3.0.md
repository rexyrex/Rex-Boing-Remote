A window for the whole fleet, and a look that is Remote's own.

**The window**
- The window is now an ordinary resizable one, in the Dock and ⌘-Tab while it is open, with your servers down a sidebar. It remembers its size and what it was showing, and opens on your only (or your pinned) server.
- **All Servers** shows the fleet as tiles: each server's character, a CPU trace, its vitals and whatever needs attention.
- A server shows a strip of headline readings over every card with its detail already open, in up to three columns, with five minutes of history in the graphs.
- The popover's header has a button that hands over to the window, on the server the popover was showing. The window can also open at launch (Settings › General).

**A look of its own**
- Remote no longer borrows Rex Boing's blue. Its violet leads its name, its characters, its headers and its window.
- Every rex in the menu bar has a signal mark beside it: violet while the server answers, faded while it doesn't.
- Every dashboard starts with a banner naming the machine it reads, how the app reaches it, what it runs and whether the numbers are still arriving.
- New icon: the rex on a server stack, which still reads at Finder and ⌘-Tab sizes.

**Dashboards**
- Filesystems show fullness as `df` counts it: ext4's reserve for root no longer counts as data. (Needs the 0.3.0 agent on Linux.)
- History's busiest processes name an interpreter's script (`node …/server.js`), as Top Processes does.
- A reconnect brings back up to 600 samples of the graphs instead of the last 90.
- A dashboard still showing in the window keeps its process table live when the popover closes.
- VoiceOver reads the menu bar rexes and can open a server from the fleet list.

**Staying connected**
- A dropped link is reported as a drop, whatever the server's login scripts print on the way in, instead of "The agent is missing" with five-minute retries.
- An agent that dies right after its first sample is retried with backoff instead of every second.
- The app's key is rebuilt from its private half when the public half goes missing, rather than replaced, which broke every server.
- A server list written by another version loads: what this version doesn't know takes its default instead of emptying the fleet.
- Repair and adding a server again keep a rename, pin, character or history choice made while they ran.
- Quick `ssh` commands no longer sometimes wait out a ten-second timeout, which delayed reconnects.

**Security**
- Pairing codes that could run a command on this Mac are refused: a user name read as an `ssh` option, or a host key carrying a line break. Every `ssh` command line also ends its options before the destination.
- The macOS agent takes an upgrade only when it is signed by the team that signed the agent itself, and it keeps every other key in `authorized_keys` when it edits the file.
- `install` and `uninstall` refuse to run as root on someone else's home (a `sudo` that keeps `HOME`), which left root-owned files `sshd` could not read.

**Linux agent**
- Containers (Docker, LXC, Proxmox CT, nspawn) report network traffic; a failover VF is counted once; 32-bit counters are followed across their wrap.
- A dying disk or hung controller no longer freezes samples: drive temperatures are read off the sampling path. SATA temperatures are read only for an open dashboard, so they no longer keep a NAS's disks spinning.
- One slow sensor read no longer slows the CPU temperature to every 10 s for good.
- Big cores binned a little lower are P cores, not E (RK3588S); boards whose temperatures come from thermal zones report CPU and GPU temperature.
- A process born since the last scan shows its CPU instead of 0 %, so a build's compilers rank where they belong.
- A disk mounted under `/var/lib/docker` and the like is listed again; Proxmox and cgroup v1 containers are counted.

**NVIDIA (Linux and Windows)**
- A reading `nvidia-smi` can no longer refresh is dropped instead of repeated, and readings come back after a driver reload or reboot. `doctor` reports `nvidia-smi`'s own error.
- On Linux, a runtime-suspended laptop GPU is reported idle without waking it.

**Windows agent**
- Peak temperature counts CPU, GPU and SoC sensors only, as on Linux.
- New processes show their CPU instead of 0 %.
- The background agent no longer closes a pipe handle twice.

**Background history**
- A background agent that restarts mid-window keeps that window's half-minute and five-minute points.
- A process reading that is not a number no longer drops every process table from history for up to a day.
- After an upgrade or a repeated install, the background agent restarts on the new version and is waited for, so the next session gets its history.
- `serve` run by hand saves its history when its terminal closes.

**Installers**
- `install.sh` works where `/tmp` is mounted `noexec`, checks the signature on servers with `sshd` but no `ssh` client, and `--uninstall` cleans up even when the agent's file is already gone.
- `install.ps1` leaves TLS 1.3 available and picks the ARM64 agent under an emulated x64 PowerShell.

To get the agent fixes on a server already set up, press **Update Agent** in Settings › Servers (or **Repair…**, for a server reached through your own SSH setup).
