The first release of Rex Boing Remote: your Linux, macOS and Windows servers in the Mac menu bar, with Rex Boing's cards and characters.

**Adding servers**
- Pick a host from your `~/.ssh/config` or your network and press Add. Passwords, codes and new host keys are asked for once, in a dialog.
- Or run one command on the server and paste the pairing code it prints. The code pins the server's host keys and lists every address it can be reached at.

**Staying connected**
- Reconnects after sleep, reboots on either side and network changes, with backoff and a watchdog for silent links.
- Uses its own key, restricted on the server to starting the agent, so reconnecting never needs you or your SSH agent.

**What it shows**
- CPU per core, GPU engines, memory and swap, every temperature sensor and fan, power, pressure stall, network, disks and filesystems, top processes, reboot-needed, updates and failed services.

**Agents**
- Linux: x86-64, ARM64, ARMv6/7. macOS 14+: Rex Boing's own samplers. Windows 10/11, Server 2019+ (amd64, arm64).
- The Windows agent is a preview: it has been tested on GitHub's Windows runners, not yet on a range of real PCs. Reports from `rex-boing-agent.exe doctor` are very welcome.

Requires macOS 14 or later on the Mac.
